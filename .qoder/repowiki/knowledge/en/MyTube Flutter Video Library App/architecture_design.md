Single Flutter package (`pubspec.yaml` defines `mytube`) whose runtime splits across two child modules: the Dart/Flutter codebase (domain, data, features, sources, playback) and the Android host in `platform_integration` that embeds the Flutter engine. Cross-child wiring happens through two custom MethodChannel plugins declared by the Android side and consumed from Dart to reach MediaStore, Storage Access Framework, thumbnails, PiP, and media session. The shared boundary contract is the `VideoSourceAdapter` interface plus the Drift schema (`video_items`, `source_locations`, tags/collections/downloads/preferences) — both children depend on these abstractions so the Dart domain stays decoupled from Android storage APIs. Tests under `test/` exercise the same Dart layer without touching the Android host, while integration tests cover the channel boundary on device.
